# Mini Loja SOLID

Execute na pasta da aula:

```powershell
dotnet run --project MiniLojaSolid
dotnet run --project MiniLojaSolid -- --test
```

Requer SDK .NET 8. O resultado inicial é R$ 180,00. As verificações usam exceções para sinalizar falhas e não precisam de pacotes de teste externos.

Consulte a seção Laboratório na aula para as missões. Os tipos exibidos nas seções individuais são exemplos independentes; não cole todos no projeto, pois alguns nomes se repetem.
